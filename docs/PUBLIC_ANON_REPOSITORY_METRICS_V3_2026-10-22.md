# Public VSTOPIA metrics v3 — pseudonyms, branch and PR lifetimes

**Live release scope:** The organization currently exposes **20 total GitHub repositories** to the private collector. Only **13 repositories** have passed the explicit shared-access check and are represented by stable, creative, non-identifying **aliases**. Their names, code, commit subjects, pull request/issue titles, real branch refs, repository URLs and credentials are NOT in the public JSON. The 12 nature-tree branch labels remain *conceptual areas*, independent from these 13 anonymous monitored repositories. When snapshot schema 3 loads, the left sidebar shows the 13 anonymous monitored aliases instead of a second competing conceptual list; clicking an alias updates the plaintext inspector with metrics.

### Public data definitions

- **20 total**: organization repositories enumerated by the authorized collector, including ones not monitored. **13 monitored**: repositories accessible to the two approved team members under the private collector's explicit permission check; this is the denominator for the per-alias activity totals. It will change as access or inventories change. Do not imply all 20 have been scanned.
- **Per alias:** default-branch commits, open Issues, open PRs, total merged PRs, number of branches (including default), number of non-default branches, oldest open PR/Issue age, last *observed* GitHub activity timestamp, event type and approved actor (`ostinsolo`/`InnovateSN`, anyone else `Team`). No names of private repositories, PRs/issue titles, or source links.
- **Branches:** first-observed age, not real creation date. The private collector keeps a private state table of raw repo/branch refs and first-seen timestamps; only opaque ordinal labels such as `Ramo 01` and `observed_days` are published. **On the initial scan existing branch ages begin at zero.** Deleted branches lose their old age if later recreated.
- **Open PR ages:** exact age from GitHub `created_at`. Anonymous PR labels `PR 01`, `PR 02`; drafts flagged, pending individual reviewer requests attributed only to approved members. No PR number or URL in public payload. 24 anonymous branch and PR entries at most per alias; counts include any additional unlisted entries.
- **Work awaiting each person:** explicit open assigned issues/PRs and individual pending reviewer requests; not inferred from absence of commits. Latest events come from GitHub's rolling Events API and may be incomplete; the UI says *observed*, not guaranteed absolute latest.
- **Historical team totals:** default-branch GitHub commits, PRs and merge counts as already documented in v2. A visible UTC-based local formatted snapshot timestamp proves collection time; the browser's periodic JSON reload does not itself refresh GitHub metrics.

### Privacy and synchronization

The private alias mapping and branch observation table are stored ONLY in `VSTOPIA-GitCollab/vstopia-team-tree` (PRIVATE), never in `vstopia-team-tree-pages` (PUBLIC). The public `scripts/validate_public_snapshot.py` validates explicit schema v2/v3 fields and rejects unknown keys, unapproved collaborator IDs, private URLs and raw branch/PR labels. The private collector rejects output containing any real repository name from the hidden mapping. The HTML and JS do not access GitHub private APIs or contain credentials.

The v3 snapshot initially included in this release was generated by a **one-time authorized, manual read-only local GitHub collection** and validated before copying only its sanitized public JSON. **The hourly Action remains DISABLED** until two limited-privilege GitHub Secrets (`TEAM_TREE_READ_TOKEN`, `TEAM_TREE_PUBLISH_TOKEN`) and opt-in variable `ENABLE_PUBLIC_SNAPSHOT_SYNC=true` are configured and permissions verified. No broad personal GitHub token is stored in Actions. The initial branch observation baseline remains in PRIVATE Git so future runs can measure time from the first observation accurately.
